# HostelPro - Frontend Client

The frontend client for the Hostel Management System, built with **React 19**, **Vite 8**, and **Tailwind CSS v4**.

## 🚀 Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment variables:
   ```bash
   cp .env.example .env
   ```
   Ensure `VITE_API_URL` is set (default: `http://localhost:5000/api`).

3. Start development server:
   ```bash
   npm run dev
   ```

## 📜 Available Scripts

- `npm run dev`: Starts the Vite local development server on `http://localhost:5173`.
- `npm run build`: Compiles production assets into `dist/`.
- `npm run preview`: Previews the production build locally.
- `npm run lint`: Runs ESLint over project source files.
